議事録アクション抽出器

議事録からやるべきこと（行動候補）を拾い出し、担当と期限が書かれていないものを自動で見つける Python ツールです。表形式にも対応しています。

何をするツールか

議事録テキスト→行動候補を抽出→担当・期限を読み取り→欠落を判定

1行（または表の1行）を1件の行動として、次の項目を返します。

項目 内容
text 行動の本文
owner 担当者（読めなければ空）
start / due 開始日・期限（ISO 形式。期間なら終了日が期限）
due_text 表の期限セルに書かれていた原文
missing 欠落項目（["担当"]・["期限"]・両方）
unparsed 期限は書いてあるが日付として読めない（例：「来週中」）

判定ルール

行動とみなす行

  • 「対応・確認・送付・作成・連絡・提出」を含む行
  • ただし「作成者」「連絡先」「提出日」のように、直後に「者・先・日・済・不要」が続く言い方は行動として数えない
  • 行内に「対応済」「確認不要」などがあれば、完了・不要とみなして行ごと除外
  • 見出し行に「担当」列と「アクション／内容」列がある表は、行動語の有無に関係なく全行を行動とみなす

担当の読み取り

  • 担当：と担当者：の両方に対応。名前は読点・句点・空白（全角を含む）の手前まで
  • 「未定・未割当・調整中・TBD・－・？」は、書いてあっても担当なしとして扱う

期限の読み取り

  • 2026-09-30・2026/09/30・2026年9月30日・全角数字の ２０２６／１０／０５
  • 期間 2026/05/23～2026/09/23 は終了日を期限とし、開始日も保持（ラベル「期間：」の有無は問わない）
  • 表の 9/30・12月1日 のような年のない日付は、会議日から年を補う（12月の会議の「1/10」は翌年）
  • 日付が1つだけのときは「期限：」などのラベルが必要。本文中の関係ない日付を期限と取り違えないため
  • 9月31日のような存在しない日付や、開始日が終了日より後の期間は、読めない期限（unparsed）として扱う

判明した問題：議事録の代わりに御礼メールを拾っていた 各会話では「議事録テキスト → HTML → 御礼メール」の順にファイルが作られます。回収の条件を「冒頭に"議事録"を含む最後のファイル」としていたため、本文に「議事録」を含み、しかも最後に作られる御礼メールが選ばれていました。このため、一括実行の件数（担当・期限の欠落率）はまだ正しい値ではありません。

わかった議事録の書き方と、次の改修

  • アクションの書き方は3通り：①表（担当｜アクション｜期限）②「■ ネクストアクション」の見出しの下に【弊社側】【先方側】のグループを立てる形 ③「・[鈴木]資料を共有(当日中)」と担当を［］、期限を（）で書く形
  • 回収をやり直す：ファイル名に「議事録」を含み「メール・御礼」を含まないものを優先し、Markdown を優先する
  • 抽出は「ネクストアクション」などの見出しの範囲内だけを読む（御礼メールや提案本文の誤検知を防ぐ）
  • 担当は ［X］・【X】・グループ見出しの引き継ぎから、期限は行末の（ ）から読む
  • 期限の欠落は「日付あり／相対表現あり（当日中・近日中など）／記載なし」の3区分で報告する
  • 合格基準：アクション見出しの検出率と、無作為に選んだ10件の目視照合

"""議事録から行動候補を抽出し、担当・期限の欠落を検知する。"""
import re
from datetime import date

ACTION_WORDS = ("対応", "確認", "送付", "作成", "連絡", "提出")
# 完了済み・不要・名詞用法（作成者／連絡先／提出日 等）は行動とみなさない
ACTION = re.compile("(?:" + "|".join(ACTION_WORDS) + ")(?!済|不要|者|先|日)")
# 「連絡は対応済み」のように、行内に完了・不要の表現があれば行ごと除外
DONE = re.compile("(?:" + "|".join(ACTION_WORDS) + ")(?:済|不要)")
# 「担当：」「担当者：」の両方。名前は読点・句点・空白（全角含む）の手前まで
OWNER = re.compile(r"担当者?\s*[:：]\s*([^、,，。\s]+)")
# 担当欄が埋まっていても実質未決のもの
OWNER_PLACEHOLDERS = {"未定", "未割当", "未割り当て", "調整中", "TBD", "tbd", "-", "－", "ー", "?", "？"}
# 2026-09-30 / 2026/09/30 / 2026年9月30日（全角数字も可）
DATE = r"(\d{4})\s*[/／\-－年.]\s*(\d{1,2})\s*[/／\-－月.]\s*(\d{1,2})日?"
RANGE_SEP = r"\s*[～〜~]\s*"
# 期間：開始～終了（ラベル省略可）→ 終了日を期限とみなす
RANGE = re.compile(r"(?:(?:期限|期間|納期)\s*[:：]\s*)?" + DATE + RANGE_SEP + DATE)
# 期限：日付（単一日付はラベル必須＝本文中の無関係な日付を拾わない）
SINGLE = re.compile(r"(?:期限|期間|納期)\s*[:：]\s*" + DATE)
DUE_LABEL = re.compile(r"(?:期限|期間|納期)\s*[:：]")


def _to_date(y, m, d):
    try:
        return date(int(y), int(m), int(d))
    except ValueError:
        return None


def _parse_due(line):
    """(start, due, unparsed) を返す。期限らしき記載があるのに読めなければ unparsed=True。"""
    m = RANGE.search(line)
    if m:
        start, end = _to_date(*m.group(1, 2, 3)), _to_date(*m.group(4, 5, 6))
        if start and end and start <= end:
            return start, end, False
        return None, None, True
    m = SINGLE.search(line)
    if m:
        due = _to_date(*m.group(1, 2, 3))
        return None, due, due is None
    return None, None, bool(DUE_LABEL.search(line))


def extract_candidates(minutes):
    results = []
    for number, line in enumerate(minutes.splitlines(), 1):
        if not ACTION.search(line) or DONE.search(line):
            continue
        owner = OWNER.search(line)
        if owner and owner.group(1) in OWNER_PLACEHOLDERS:
            owner = None
        start, due, unparsed = _parse_due(line)
        missing = []
        if not owner:
            missing.append("担当")
        if not due:
            missing.append("期限")
        results.append({"line": number, "text": line.strip(),
                        "owner": owner.group(1) if owner else None,
                        "start": start.isoformat() if start else None,
                        "due": due.isoformat() if due else None,
                        "missing": missing,
                        "unparsed": unparsed})
    return results


# ---- 表形式（| 担当 | アクション | 期限 | ...）のアクション表 ----
OWNER_COL = re.compile(r"担当|誰が|責任者")
TASK_COL = re.compile(r"アクション|タスク|内容|項目|やること|対応事項")
DUE_COL = re.compile(r"期限|期日|納期|いつまで|時期")
# 年なしの日付（9/30・9月30日）。年は会議日から補う
MONTH_DAY = re.compile(r"(?<!\d)(\d{1,2})\s*[/／月]\s*(\d{1,2})日?(?!\d)")
EMPTY_CELL = {"", "-", "－", "ー", "—", "―", "なし", "TBD", "tbd", "未定", "要確認", "調整中", "期限なし"}


def _cells(line):
    return [c.strip() for c in line.strip().strip("|").split("|")]


def _is_separator(line):
    return bool(re.fullmatch(r"\|?\s*:?-{2,}:?\s*(\|\s*:?-{2,}:?\s*)*\|?", line.strip()))


def _parse_due_cell(cell, base):
    """表の期限セル → (start, due, unparsed)。日付でない記載（当日中・来週 等）は unparsed。"""
    if cell in EMPTY_CELL:
        return None, None, False
    start, due, unparsed = _parse_due("期限：" + cell)
    if due:
        return start, due, False
    m = MONTH_DAY.search(cell)
    if m and base:
        due = _to_date(base.year, *m.groups())
        if due and (base - due).days > 180:  # 12月の会議で「1/10」→翌年
            due = _to_date(base.year + 1, *m.groups())
        if due:
            return None, due, False
    return None, None, True


def extract_from_tables(minutes, base=None):
    """見出し行に「担当」列と「アクション／内容」列を持つ表の全行を行動として扱う。"""
    results, header = [], None
    lines = minutes.splitlines()
    for number, line in enumerate(lines, 1):
        if not line.strip().startswith("|"):
            header = None
            continue
        if _is_separator(line):
            continue
        cells = _cells(line)
        nxt = lines[number] if number < len(lines) else ""
        if _is_separator(nxt) or header is None:
            cols = {"owner": None, "task": None, "due": None}
            for i, c in enumerate(cells):
                for key, pat in (("owner", OWNER_COL), ("task", TASK_COL), ("due", DUE_COL)):
                    if cols[key] is None and pat.search(c):
                        cols[key] = i
                        break
            is_header = cols["owner"] is not None and cols["task"] is not None
            if _is_separator(nxt) or is_header:
                header = cols if is_header else None
                continue
        if header is None or DONE.search(line):
            continue
        get = lambda k: cells[header[k]] if header[k] is not None and header[k] < len(cells) else ""
        owner = get("owner")
        owner = None if owner in EMPTY_CELL or owner in OWNER_PLACEHOLDERS else owner
        due_text = get("due")
        start, due, unparsed = _parse_due_cell(due_text, base)
        missing = ([] if owner else ["担当"]) + ([] if due else ["期限"])
        results.append({"line": number, "text": get("task") or line.strip(),
                        "owner": owner, "start": start.isoformat() if start else None,
                        "due": due.isoformat() if due else None, "due_text": due_text or None,
                        "missing": missing, "unparsed": unparsed})
    return results


def extract_all(minutes, base=None):
    """アクション表があれば表を正とし、無ければ行ベース抽出にフォールバックする。"""
    rows = extract_from_tables(minutes, base)
    return (rows, "table") if rows else (extract_candidates(minutes), "line")
