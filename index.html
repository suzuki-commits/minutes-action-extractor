議事録アクション抽出器

議事録から「やるべきこと」を拾い出し、担当と期限が書かれていないものを自動で見つける Python ツールです。社内の議事録709件に一括適用し、抽出の精度を目視で照合しました。

何をするツールか

議事録テキスト→行動一覧の場所を特定→担当・期限を読み取り→欠落を判定

行動1件ごとに、次の項目を返します。

項目内容
text行動の本文
owner担当者（読めなければ空）
start / due開始日・期限（ISO 形式。期間なら終了日が期限）
due_kind期限の種類：日付／相対表現（当日中・来週中 など）／記載なし
due_text期限として書かれていた原文
missing欠落項目（["担当"]・["期限"]・両方）

行動一覧の見つけ方

議事録の全文を読むと、提案内容や御礼の文面まで行動と誤認します。そこで行動一覧が書かれている場所だけを読みます。次の順に試し、最初に見つかった方式を採用します。

どちらも見つからない議事録は「行動一覧なし」として一覧に出し、全文からの推測はしません。

判定ルール

行動から外すもの

  • 文末が「対応済み」「確認不要」「完了」の項目（もう終わっている／やらない）
  • ただし「確認済みの見積を送付」のように、完了表現が途中にあるだけなら行動として残す
  • 「作成者」「連絡先」「提出日」のような、人や物を指す言葉

担当

  • 担当：・担当者：、行頭の [鈴木]・【鈴木】・鈴木：、表の担当列、直前のグループ見出し（【弊社側】・■加藤様・村田氏側 など）
  • 「予算検討：」「日程調整：」のような項目名は担当として読まない
  • 「未定・TBD・調整中・要確認・－」は、書いてあっても担当なし

期限（3区分）

  • 日付：2026/09/30・2026年9月30日・全角数字・期間 2026/05/23～2026/09/23（終了日）・年のない 9/30 や 10/1〜10/15（会議日から年を補い、範囲は終了日）
  • 相対表現：当日中・本日中・即日は会議日に換算して期限あり。近日中・来週中・随時・次回などは日付にできないため「期限なし」扱い（区分は相対表現として別に数える）
  • 記載なし：期限の手がかりが何もない
  • 会議日は会話の作成日時を日本時間に直した日付（UTC のままだと朝の会議が前日になる）

これまでの修正の経緯

  • 回収の取り違え：最初の回収では、議事録ではなく御礼メールを319件拾っていました。ファイル名に「議事録」を含み、「メール・御礼」を含まないものを優先する条件に直し、再回収後の混入は0件です。
  • 全文走査の誤検知：当初は全行から行動語を探していたため、提案内容や御礼文を行動と誤認していました。行動一覧の範囲だけを読む方式に変えました（行動一覧を検出できた議事録は95%）。
  • 書式の追加対応：照合で見つかった書式（縦並び・担当ラベル行・担当小見出し配下の表・「○○のアクション」・完了の表記ゆれ など）を、匿名化したうえで内蔵テストに加えています。

"""議事録から行動候補を抽出し、担当・期限の欠落を検知する。

対応する書き方（extract_all が上から順に試す）:
  1. 表     | 担当 | アクション | 期限 |
  2. 見出し ■ ネクストアクション → 【弊社側】→ ・[鈴木]資料を送付（当日中）
  3. 行     資料を送付。担当：鈴木 期限：2026-09-30（extract_candidates を直接呼ぶ場合）
"""
import re
from datetime import date

ACTION_WORDS = ("対応", "確認", "送付", "作成", "連絡", "提出")
# 完了済み・不要・名詞用法（作成者／連絡先／提出日 等）は行動とみなさない
ACTION = re.compile("(?:" + "|".join(ACTION_WORDS) + ")(?!済|不要|者|先|日)")
DONE = re.compile("(?:" + "|".join(ACTION_WORDS) + r")(?:済み?|不要)|完了|(?<![決返経救])済み?")
# 完了・不要の表現が文末にあれば、その行の述語は完了済み（「連絡は対応済み」）
DONE_AT_END = re.compile(r"[\s。．.、）)]*$")
# 「担当：」「担当者：」の両方。名前は読点・句点・空白（全角含む）の手前まで
OWNER = re.compile(r"担当者?\s*[:：]\s*([^、,，。\s()（）]+)")
# 担当欄が埋まっていても実質未決のもの
OWNER_PLACEHOLDERS = {"未定", "未割当", "未割り当て", "調整中", "TBD", "tbd", "-", "－", "ー", "—", "―", "?", "？", "要確認"}
EMPTY_CELL = {"", "-", "－", "ー", "—", "―", "なし", "TBD", "tbd", "未定", "要確認", "調整中", "期限なし"}

# 2026-09-30 / 2026/09/30 / 2026年9月30日（全角数字も可）
DATE = r"(\d{4})\s*[/／\-－年.]\s*(\d{1,2})\s*[/／\-－月.]\s*(\d{1,2})日?"
# 年なしの日付（9/30・9月30日）。年は会議日から補う
MD = r"(?<![\d/／])(\d{1,2})\s*[/／月]\s*(\d{1,2})日?(?![\d/／])"
RANGE_SEP = r"\s*[～〜~]\s*"
FULL_RANGE = re.compile(DATE + RANGE_SEP + DATE)
FULL_DATE = re.compile(DATE)
MD_RANGE = re.compile(MD + RANGE_SEP + r"(?:(\d{1,2})\s*[/／月]\s*)?(\d{1,2})日?")
MD_DATE = re.compile(MD)
DUE_LABEL = re.compile(r"(?:期限|期間|納期|期日)\s*[:：]\s*([^\s、,，。|]*)")
# 会議日に換算できる相対表現／換算できない相対表現
SAME_DAY = re.compile(r"当日|本日|即日|今日中")
# 「12月中」「1月初旬」のように月の付いた相対表現（due_text に月まで残すため）
MONTH_REL = re.compile(r"\d{1,2}月(?:中|末|内|上旬|中旬|下旬|初旬|頃|ごろ|以降)")
RELATIVE = re.compile(r"近日|今週|来週|翌週|再来週|今月|来月|月内|月末|月中|週内|週末|年内|中旬|上旬|下旬|初旬|以内|次回|後日|"
                      r"随時|早急|至急|速やか|すみやか|早め|早期|追って|別途|継続|定期|毎週|毎月|明日|翌日|明後日|翌営業日|"
                      r"即座|即時|直後|要調整|適宜|までに|後$|以降|以後|頃|ごろ|今後")


def _to_date(y, m, d):
    try:
        return date(int(y), int(m), int(d))
    except ValueError:
        return None


def _with_year(m, d, base):
    """年なしの月日に会議日の年を補う（12月の会議で「1/10」→翌年）。"""
    if not base:
        return None
    due = _to_date(base.year, m, d)
    if due and (base - due).days > 180:
        due = _to_date(base.year + 1, m, d)
    return due


def parse_due_text(text, base=None):
    """期限の記載 → {start, due, kind, due_text}。

    kind: "date"（日付で読めた）／"relative"（当日中・来週中 などの相対表現）／"none"（記載なし）。
    相対表現のうち当日中・本日中・即日は会議日に換算して due に入れる。
    """
    text = (text or "").strip()
    out = {"start": None, "due": None, "kind": "none", "due_text": text or None}
    if text in EMPTY_CELL:
        return out
    m = FULL_RANGE.search(text)
    if m:
        start, end = _to_date(*m.group(1, 2, 3)), _to_date(*m.group(4, 5, 6))
        if start and end and start <= end:
            return {**out, "start": start, "due": end, "kind": "date"}
        return {**out, "kind": "relative"}  # 存在しない日付・逆転した期間は読めない記載として扱う
    m = FULL_DATE.search(text)
    if m:
        due = _to_date(*m.groups())
        return {**out, "due": due, "kind": "date" if due else "relative"}
    m = MD_RANGE.search(text)
    if m and base:
        m1, d1, m2, d2 = m.groups()
        start, end = _with_year(m1, d1, base), _with_year(m2 or m1, d2, base)
        if start and end and end < start:
            end = _to_date(end.year + 1, end.month, end.day)
        if start and end:
            return {**out, "start": start, "due": end, "kind": "date"}
    m = MD_DATE.search(text)
    if m and base:
        due = _with_year(*m.groups(), base)
        if due:
            return {**out, "due": due, "kind": "date"}
    if SAME_DAY.search(text):
        return {**out, "due": base, "kind": "relative"}
    return {**out, "kind": "relative"}


def _is_done(text):
    """完了・不要の表現が文頭（「完了 - 資料送付」）か文末にある（＝もう終わっている／やらない）。

    文末の括弧が「（完了）」なら完了、「（友達申請完了済）」のように内訳の説明なら本体は未完了とみなす。
    """
    text = text.strip()
    if re.match(r"^(?:完了済み?|完了|済み?|対応済み?)\s*[-－–—:：]", text):
        return True
    paren = re.search(r"[（(]([^（）()]*)[)）]\s*[。．.]?$", text)
    if paren and not FINISHED.match(paren.group(1).strip()):
        text = text[:paren.start()]
    return any(DONE_AT_END.fullmatch(text, m.end()) for m in DONE.finditer(text))


def _is_action(text):
    """完了済みの修飾（「確認済みの見積を送付」）を除いた残りに行動語があるか。"""
    return not _is_done(text) and bool(ACTION.search(DONE.sub("", text)))


def _row(line, text, owner, due_info):
    owner = None if not owner or owner in OWNER_PLACEHOLDERS else owner
    due = due_info["due"]
    missing = ([] if owner else ["担当"]) + ([] if due else ["期限"])
    return {"line": line, "text": text, "owner": owner,
            "start": due_info["start"].isoformat() if due_info["start"] else None,
            "due": due.isoformat() if due else None,
            "due_text": due_info["due_text"], "due_kind": due_info["kind"],
            "missing": missing, "unparsed": due_info["kind"] == "relative" and not due}


# ---- 3. 行ベース（担当：／期限： のラベル付き） ----
def extract_candidates(minutes, base=None):
    results = []
    for number, line in enumerate(minutes.splitlines(), 1):
        if not _is_action(line):
            continue
        owner = OWNER.search(line)
        rng = FULL_RANGE.search(line)  # 期間はラベルなしでも可
        label = DUE_LABEL.search(line)
        if rng:
            due_info = parse_due_text(rng.group(0), base)
        elif label:
            due_info = parse_due_text(label.group(1) or "?", base)
        else:
            due_info = parse_due_text("", base)
        results.append(_row(number, line.strip(), owner.group(1) if owner else None, due_info))
    return results


# ---- 1. 表形式 ----
OWNER_COL = re.compile(r"担当|誰が|責任者|主体")
TASK_COL = re.compile(r"アクション|タスク|内容|項目|やること|対応事項|ToDo|TODO")
DUE_COL = re.compile(r"期限|期日|納期|いつまで|時期")


def _cells(line):
    return [c.strip() for c in line.strip().strip("|").split("|")]


def _is_separator(line):
    return bool(re.fullmatch(r"\|?\s*:?-{2,}:?\s*(\|\s*:?-{2,}:?\s*)*\|?", line.strip()))


def _heading_level(s):
    """見出し行ならその階層（# の数／■=2／▼・【】・絵文字=3）、見出しでなければ None。"""
    m = re.match(r"^(#{1,6})\s", s)
    if m:
        return len(m.group(1))
    if s.startswith("■"):
        return 2
    if re.match(r"^[▼▽●◆◇▶►【]", s) or (EMOJI.match(s) and len(s) <= 30):
        return 3
    return None


def _heading_owner(s):
    """「### コミクス（鈴木）担当」「▼ 田中様側」→ 担当名。担当を表さない見出しなら None。"""
    name = re.sub(r"^(#{1,6}\s*|[■▼▽●◆◇▶►]\s*)", "", EMOJI.sub("", s)).strip(" 【】[]：:")
    m = GROUP_SUFFIX.match(name)
    if m:
        return _clean_owner(m.group(1))
    if re.fullmatch(r"(両社|双方|両者)(共同|共通)?", name) or (GROUP_TAIL.search(name) and not ACTION.search(name)):
        return _clean_owner(re.sub(r"[:：]$", "", name))
    return None


def extract_from_tables(minutes, base=None):
    """アクション表の全行を行動として扱う。

    採用する表: 見出し行に「担当」列と「アクション／内容」列がある表。
    または、ネクストアクション見出しの配下にあり「アクション」列と「期限」列がある表
    （担当は「### コミクス（鈴木）担当」のような直前の小見出しから引き継ぐ）。
    """
    results, header = [], None
    in_action, action_level, ctx_owner = False, 0, None
    lines = minutes.splitlines()
    for number, line in enumerate(lines, 1):
        if not line.strip().startswith("|"):
            header = None
            s = line.strip()
            level = _heading_level(s) if s else None
            if level is not None:
                owner = _heading_owner(s)
                if ACTION_HEAD.search(s) and not owner:
                    in_action, action_level, ctx_owner = True, level, None
                elif in_action and owner:  # 【内田様側】・### 鈴木（コミクス）担当 は範囲内の担当見出し
                    ctx_owner = owner
                elif in_action and level <= action_level:
                    in_action, ctx_owner = False, None
                elif in_action:
                    ctx_owner = None
            continue
        if _is_separator(line):
            continue
        cells = _cells(line)
        nxt = lines[number] if number < len(lines) else ""
        if _is_separator(nxt) or header is None:
            cols = {"owner": None, "task": None, "due": None}
            for i, c in enumerate(cells):
                for key, pat in (("owner", OWNER_COL), ("task", TASK_COL), ("due", DUE_COL)):
                    if cols[key] is None and pat.search(c):
                        cols[key] = i
                        break
            is_header = cols["task"] is not None and (
                cols["owner"] is not None or (in_action and cols["due"] is not None))
            if _is_separator(nxt) or is_header:
                header = cols if is_header else None
                continue
        if header is None:
            continue
        get = lambda k: cells[header[k]] if header[k] is not None and header[k] < len(cells) else ""
        task, due_text = re.sub(r"\*\*|__", "", get("task")).strip(), get("due")
        if not task or _is_done(task) or due_text.startswith("完了"):
            continue
        owner = get("owner") if header["owner"] is not None else ctx_owner
        results.append(_row(number, task, owner or None, parse_due_text(due_text, base)))
    return results


# ---- 2. 見出し範囲（■ ネクストアクション の下の箇条書き） ----
# 「アクション」単独は見出しがそれだけのときに限る（「短期アクション（1週間以内）」のような別節の小見出しを除く）
ACTION_HEAD = re.compile(r"ネクストアクション|次のアクション|次回アクション|今後のアクション|アクションアイテム|アクションプラン|"
                         r"^[\W\d_]*アクション\s*[（(]?[^）)]{0,12}[)）]?\s*[:：]?$|"
                         r"ToDo|TODO|To ?Do|宿題|今後の対応|今後の進め方|次のステップ|ネクストステップ|Next ?Action|対応事項|タスク", re.I)
# 「-」は後ろに空白があるときだけ箇条書き（「---」の罫線と区別）。□ はチェックボックス式の箇条書き
BULLET = re.compile(r"^\s*(?:- \[[ xX]\]|-\s|[・\*•○◦▪☐□✓✔→◎]|\d{1,2}[\.．、)）]|[（(]\d{1,2}[)）]|[①-⑳])\s*(.+)$")
SECTION_END = re.compile(r"^\s*(?:#{1,6}\s|■|[─━═＝=\-_]{3,})")
SUBHEAD = re.compile(r"^\s*[▼▽●◆◇▶►]\s*(.+?)\s*$")
GROUP = re.compile(r"^\s*[【\[［<＜〈]\s*(.{1,20}?)\s*[】\]］>＞〉]\s*[:：]?\s*$|^\s*([^\s・\-*]{1,15}?)\s*[:：]\s*$")
ITEM_OWNER = re.compile(r"^[【\[［〈]\s*([^】\]］〉]{1,20}?)\s*[】\]］〉]\s*|^([^\s:：、。（(]{1,12})\s*[:：]\s*")
TRAIL_PAREN = re.compile(r"[（(]([^（）()]{1,30})[)）]\s*[。．.]?\s*$")
OWNERISH = re.compile(r"側|様|さん|氏|弊社|当社|御社|貴社|先方|両者|双方|全員|コミクス|チーム|部$")
TOPIC_WORD = re.compile(r"調整|確認|検討|共有|日程|資料|予算|目的|内容|方法|効果|期間|範囲|次回|会場|準備|連絡|報告|提案|契約|見積|"
                        r"事項|決定|課題|概要|要約|議論|背景|費用|料金|詳細|補足|備考|結論|方針|計画|戦略|施策|導入|実施")
NOT_OWNER = re.compile(r"期限|期日|期間|納期|担当|目的|内容|備考|方法|理由|背景|補足|※")


def _is_heading(line):
    s = line.strip()
    return bool(s) and len(s) <= 40 and not BULLET.match(line) and bool(ACTION_HEAD.search(s))


def _clean_owner(name):
    name = re.sub(r"側$", "", name.strip())
    return name or None


def _item(text, group_owner, base):
    owner = None
    m = ITEM_OWNER.match(text)
    if m and m.group(2) and not (GROUP_TAIL.search(m.group(2)) or
                                 (len(m.group(2)) <= 3 and not TOPIC_WORD.search(m.group(2)))):
        m = None  # 「予算検討：」「日程調整：」は項目名であって担当者ではない
    if m and not NOT_OWNER.search(m.group(0)):
        owner = _clean_owner(m.group(1) or m.group(2))
        text = text[m.end():]
    inline = OWNER.search(text)
    if not owner and inline:
        owner = inline.group(1)
    owner = owner or group_owner
    due_info = None
    paren = TRAIL_PAREN.search(text)
    if paren:
        info = parse_due_text(paren.group(1), base)
        if info["kind"] == "date" or SAME_DAY.search(paren.group(1)) or RELATIVE.search(paren.group(1)):
            due_info = info
    if not due_info:
        label = DUE_LABEL.search(text)
        if label:
            due_info = parse_due_text(label.group(1) or "?", base)
    if not due_info:
        info = parse_due_text(text, base)
        dated = info["kind"] == "date"
        rel = SAME_DAY.search(text) or RELATIVE.search(text)
        if dated or rel:
            info["due_text"] = (FULL_RANGE.search(text) or FULL_DATE.search(text) or MD_DATE.search(text)
                                or MONTH_REL.search(text) or rel).group(0)
            due_info = info
        else:
            due_info = parse_due_text("", base)
    return owner, due_info


# HTML 由来の議事録: 絵文字見出し・記号なしの項目・「・」と本文の改行分離がある
EMOJI = re.compile(r"^[\U0001F000-\U0001FFFF☀-➿⬀-⯿️‍\s]+")
# 行末が担当者らしい語で終わる短い行＝グループ見出し（「さくら商会様(青木様)」「村田氏側」「中村氏：」「コミクス(鈴木)」）
GROUP_TAIL = re.compile(r"(?:(?:側|様|氏|さん|殿|弊社|当社|御社|貴社|先方|両者|双方|全員|コミクス|チーム)"
                        r"\s*(?:[（(][^）)]{0,30}[)）])?"
                        r"|[（(][^）)]{0,20}(?:様|氏|さん|側)[)）])\s*[:：]?$")  # 「〇〇教室（佐野氏）」
# 「コミクス（鈴木氏）の担当事項」「### 田中様 担当」
GROUP_SUFFIX = re.compile(r"^(?!今後|次回|次の|ネクスト|全体|その他|共通)(.{1,25}?)\s*"
                          r"(?:(?:の|側の)?\s*(?:担当事項|担当分|担当)|(?:の|側の)\s*(?:アクション|タスク|対応事項|対応|ToDo))\s*[:：]?$")
# 署名・問い合わせ先（行動一覧の後ろに続くことが多い）＝範囲の終わり
CONTACT = re.compile(r"https?://|@[\w.-]+\.\w|お問い合わせ|作成いたしました|ご不明点|お気軽に|Tel[:：]|TEL[:：]")
# 担当・行動・期限を1行ずつ縦に並べる書式の「担当だけの行」
NAME_ONLY = re.compile(r"^(?:[一-龥々]{1,4}|.{1,10}(?:様|氏|さん)|双方|両者|両社|弊社|当社|先方|全員|コミクス)$")
# 項目の補足行（項目にも範囲の終わりにもしない）
NOTE_LABEL = re.compile(r"^(?:詳細|備考|補足|目的|内容|方法|理由|背景|注記|注意|参加者|ステータス|状態|優先度|進捗|メモ|※)\s*[:：]")
FINISHED = re.compile(r"^(?:完了|完了済み?|対応済み?|済み?)$")
# 範囲内に現れたら別の節に移ったとみなす見出し語
OTHER_HEAD = re.compile(r"特記事項|作成日|作成者|連絡体制|お問い合わせ|署名|今後の展望|期待効果|効果|参加者|概要|サマリー|要約|議論|討議|決定事項|合意事項|課題|費用|料金|"
                        r"スケジュール|重要ポイント|ポイント|備考|補足|詳細|背景|提案内容|所感|考察|リスク|まとめ|メモ|要確認|"
                        r"基本情報|会議情報|次回予定|次回会議|添付|関連資料|懸念")
# 絵文字・記号付きの見出しのときだけ別節とみなす語（項目本文にも出る語なので記号なしの行には適用しない）
INFO_HEAD = re.compile(r"会食|イベント|情報|案内|料金|価格|実績|事例|紹介|について|カレンダー")
LABELED_ITEM = re.compile(r"^(期限|期日|納期|担当者?|優先度|優先)\s*[:：]\s*([^-－–—]{1,15}?)\s+[-－–—]\s*(.{2,})$")
LEAD_LABEL = re.compile(r"^(期限|期日|納期|担当者?)\s*[:：]\s*(.*)$")


def _merge_lone_bullets(lines):
    """「・」だけの行と次の行を1行にまとめる（HTML の li 変換で分かれるため）。行番号は後ろの行に合わせる。"""
    out, pending = [], None
    for number, line in enumerate(lines, 1):
        s = line.strip()
        if re.fullmatch(r"[・\-\*•●○◦▪]", s):
            pending = s
            continue
        if pending and s:
            line, pending = pending + line.strip(), None
        out.append((number, line))
    return out


def extract_from_sections(minutes, base=None):
    results, seen = [], set()
    in_section, group, has_body = False, None, False
    # last=直前の項目 / fresh=直前に処理した行がその項目（補足行は挟んでよい） / pending=次の項目に付ける担当
    last, last_fresh, pending = None, False, None
    for number, line in _merge_lone_bullets(minutes.splitlines()):
        s = EMOJI.sub("", line.strip())
        if not s:
            continue
        fresh, last_fresh = last_fresh, False
        if in_section and not BULLET.match(s):
            raw = line.strip()
            if GROUP_SUFFIX.match(re.sub(r"^[■▼▽●◆◇▶►#\s]+", "", s)) or _heading_level(raw) is not None:
                owner = _heading_owner(raw)
                if owner:  # 「コミクス（鈴木氏）の担当事項」「### 〇〇(前田様)」「鈴木氏のアクション」
                    group, pending, has_body = owner, None, True
                    continue
            if CONTACT.search(s):
                in_section = False  # 署名・問い合わせ先
                continue
        if _is_heading(s):
            in_section, group, has_body, last, pending = True, None, False, None, None
            continue
        if not in_section or s.startswith("|"):
            continue  # 表は extract_from_tables が扱う
        boxed = re.match(r"^■\s*(.{1,30})$", s)
        if boxed and GROUP_TAIL.search(boxed.group(1)):  # 「■加藤様」＝範囲内の担当グループ
            group, pending, has_body = _clean_owner(re.sub(r"[:：]$", "", boxed.group(1))), None, True
            continue
        if SECTION_END.match(line) and not BULLET.match(line):
            # 見出し直後の飾り罫線（■ 見出し／────）は範囲の終わりではない
            in_section = not has_body
            continue
        has_body = True
        b = BULLET.match(s)
        body = b.group(1).strip() if b else s  # 「・担当者: 吉田氏」のように箇条書きに入ったラベル行も同じに扱う
        lab = LABELED_ITEM.match(body)
        if lab:  # 「期限：1週間以内 - サービス導入の検討」「優先度：高 - 所長への報告」＝ラベル付きの項目
            label, value, text = lab.groups()
            owner, due_info = _item(text, pending or group, base)
            if label.startswith("担当"):
                owner = value.strip()
            elif label[0] in "期納":
                due_info = parse_due_text(value, base)
            pending = None
            last = _row(number, text.strip(), owner, due_info)
            results.append(last)
            last_fresh = True
            continue
        if NOTE_LABEL.match(body):
            last_fresh = fresh  # 「詳細：…」は補足。直前の項目との隣接は保つ
            continue
        lead = LEAD_LABEL.match(body)
        if lead:
            label, value = lead.group(1), lead.group(2).strip()
            if label.startswith("担当"):
                if last is not None and fresh and not last["owner"]:  # 項目の次の行の「担当：」
                    last.update(_row(last["line"], last["text"], value, _due_of(last)))
                    last_fresh = True
                else:  # 項目の前に置かれた「担当：」は次の項目に付ける
                    pending = value or None
            elif last is not None and last["due_kind"] == "none":
                last.update(_row(last["line"], last["text"], last["owner"], parse_due_text(value, base)))
                last_fresh = fresh
            continue
        # 担当・行動・期限を1行ずつ縦に並べる書式（鈴木／資料を共有／本日中／✅ 完了済）
        if last is not None and fresh and not BULLET.match(s):
            if FINISHED.match(s):
                results.remove(last)
                last = None
                continue
            timing_first = re.match(r"^(?:即日|即座|即時|当日|本日|今週|来週|近日|随時|早急|至急)", s)
            if len(s) <= 15 and (timing_first or not ACTION.search(s)) and last["due_kind"] == "none":
                info = parse_due_text(s, base)
                if info["kind"] == "date" or SAME_DAY.search(s) or RELATIVE.search(s):
                    last.update(_row(last["line"], last["text"], last["owner"], info))
                    last_fresh = True
                    continue
        if NAME_ONLY.match(s) and not TOPIC_WORD.search(s) and not ACTION.search(s):
            pending = _clean_owner(s)
            continue
        g = GROUP.match(s)
        if g:
            name = g.group(1) or g.group(2)
            if g.group(2) and not (GROUP_TAIL.search(name) or (NAME_ONLY.match(name) and not TOPIC_WORD.search(name))):
                in_section = False  # 「決定事項：」「特記事項：」など担当でない見出し＝別の節
                continue
            group, pending = _clean_owner(name), None
            continue
        if not b:
            sub = SUBHEAD.match(s)
            name = re.sub(r"[:：]$", "", sub.group(1) if sub else s)
            if len(name) <= 30 and GROUP_TAIL.search(name) and not ACTION.search(name):
                group, pending = _clean_owner(name), None
                continue
            headish = (EMOJI.match(line.strip()) or re.match(r"^\s*[■□▼▽●◆◇▶►【#]", line)) \
                and not re.search(r"[:：]\s*\S", s)  # 「日程調整： 9月の…」は項目
            if sub or (len(s) <= 25 and (OTHER_HEAD.search(s) or (headish and INFO_HEAD.search(s)))):
                in_section = False  # 「▼ 次回」「今後の展望」など担当を表さない見出し＝別の節
                continue
            if len(s) > 100:
                continue  # 範囲内の説明文は項目にしない
        text = EMOJI.sub("", (b.group(1) if b else s)).strip()
        if not text or _is_done(text) or re.fullmatch(r"[\d\W_]+", text):
            continue  # 「1」だけの番号行などは項目にしない
        owner, due_info = _item(text, pending or group, base)
        pending = None
        key = (owner, re.sub(r"[\s（）()。、]", "", text))
        if key in seen:
            continue
        seen.add(key)
        last = _row(number, text, owner, due_info)
        results.append(last)
        last_fresh = True
    return results


def _due_of(row):
    """_row の出力から parse_due_text 形式の期限情報を復元する。"""
    to = lambda v: date.fromisoformat(v) if v else None
    return {"start": to(row["start"]), "due": to(row["due"]), "kind": row["due_kind"], "due_text": row["due_text"]}


def extract_all(minutes, base=None):
    """表 → 見出し範囲 の順に試し、最初に行動が取れた方式を採る。どちらも無ければ ([], "none")。"""
    for mode, fn in (("table", extract_from_tables), ("section", extract_from_sections)):
        rows = fn(minutes, base)
        if rows:
            return rows, mode
    return [], "none"
